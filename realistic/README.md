# Realistic counting experiments

Run from the repository root using `python run.py --list` or, for any included
script, `python run.py realistic scripts/SCRIPT.py --help`.

The main code families are V3.1/V3.3 for behavior, V4/V4.4 for Non-thinking,
V5 for native Thinking, V6 for structured enumeration, and
`additional_experiments/` for Appendix H.

See the [paper map](../docs/PAPER_CODE_MAP.md),
[reproduction guide](../docs/REPRODUCING.md), and
[data requirements](../docs/DATA.md). Existing `work/` and `runs/` references
describe inputs produced by preceding experiments; completed-run artifacts
are not bundled.
