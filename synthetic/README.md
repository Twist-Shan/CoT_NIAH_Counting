# Synthetic counting experiments

The paper uses `synthetic_counting_v58`, with shared numerical kernels in
`synthetic_counting_v20`. The other packages remain available because source
modules, supplemental analyses, and tests reuse them.

From the repository root:

```bash
python tools/smoke_test.py
python run.py synthetic-train --help
```

The [saved paper configuration](configs/paper_v58_saved_config.json) is checked
against the current main preset. Tiny Shakespeare is included, with its source
and checksum recorded next to the text. Model weights are regenerated by
training and are not included. See the [reproduction guide](../docs/REPRODUCING.md).
